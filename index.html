GDPR Passport Masker

GDPR Art. 5.1(c)

Redact sensitive Machine Readable Zone (MRZ) biometric data and add check-in watermarks to passport scans before submitting them to European accommodations or landlords. Designed to prevent secondary identity theft while keeping document headers clear for automated check-in verification portals.

✓ Zero Server Uploads: Decodes, masks, and renders entirely inside client HTML5 Canvas memory.
✓ AI & OCR Friendly: Soft translucent red watermark preserves top headers for check-in verification.
✓ HEIC & 300 DPI PDF: Supports iPhone camera photos and high-resolution PDF scans.
✓ Layout Auto-Detection: Intelligently adapts between 2-page spreads and single photo page crops.
