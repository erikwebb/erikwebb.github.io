GDPR Passport Masker

Instantly redact Machine Readable Zone (MRZ) biometric data and add check-in watermarks to passport scans before uploading to European hotels and vacation rentals.

✓ Zero Network Uploads: Redaction runs entirely in browser memory via HTML5 Canvas.
✓ AI Classifier Friendly: Keeps document headers unobstructed so check-in AI approves the scan.
✓ HEIC & 300 DPI PDF: Drag & drop iPhone photos or high-res PDF scans seamlessly.
✓ Layout Auto-Detection: Adapts between 2-page passport spreads and single-page crops.
